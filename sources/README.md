## ۲. إرشاد الصَّرْف باللغة العربية

| | |
|---|---|
| تعریب | منظور أحمد شاه الدِّيرَوي |
| اصل | اردو «ارشاد الصرف» (د برصغیر د مدرسو درسي کتاب) |
| خپرندوی | المكتبة الفاروقية، كراچي |
| فایل | `irshad-al-sarf/ocr-text.txt` |
| کیفیت | ⚠️ **OCR** — اصلي PDF سکن دی، متن پرت نلري. Tesseract `ara` کارول شوی. |

### ⚠️ د OCR د کیفیت خبرداری

OCR ~۸۵٪ سم دی. عام غلطۍ:

- `المجرد` → `امجرد` / `الجحرد`
- `ج` ↔ `ح` ګډوډي
- `ة` ↔ `ه`، `» «` د comma پر ځای
- **حرکات (تشکیل) ډېری وخت له منځه تللي** — دا تر ټولو خطرناکه ده

**قاعده:** له دې فایل څخه یوازې د **موندلو (lookup)** لپاره کار واخلئ.
کله چې کوم ګردان یا وزن په کوډ کې لیکئ:

1. که موضوع په *شذا العرف* کې شته → هلته یې تصدیق کړئ (بشپړ او مشکول متن).
2. که نه شته (لکه د إرشاد ځانګړي «قاعدې» یا التصريف الكبير) → **اصلي سکن شوی مخ وګورئ**، له کاروونکي یې وغواړئ.

## د دې دوو کتابونو توپیر

| | شذا العرف | إرشاد الصرف |
|---|---|---|
| مکتب | مصري / ازهري | برصغیر / دیوبندي |
| تمرکز | **د قاعدې تعلیل او دلیل** | **د ګردان عملي جدولونه** |
| د بابونو ترتیب | نصر، ضرب، فتح، فرح، كرم، حسب | **ضرب، نصر، سمع، فتح، حسب، كرم** |
| د اپلیکېشن لپاره | د قاعدې منبع | **د ګردان او د صیغې د نامه منبع** |

⚠️ **د بابونو ترتیب توپیر لري.** ځکه چې کاروونکي پښتانه دي او د برصغیر په درسي نظام کې لوستل کیږي،
اپلیکېشن باید **د إرشاد الصرف ترتیب** (ضرب، نصر، سمع، فتح، حسب، كرم) وکاروي،
خو دواړه شمېرې باید په ډاټا کې وساتل شي. وګورئ `docs/sarf/02-abwab.md`.
