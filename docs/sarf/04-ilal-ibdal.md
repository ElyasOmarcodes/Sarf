# ۴. الإعلال والإبدال 🔴

> منبع: شذا العرف `page1_0129`–`0154` | إرشاد الصرف مخ ۱۰۶–۱۴۰ (قواعد)

**دا د اپلیکېشن اصلي موضوع ده** (README: «د علم صرف د بابونو د اعلال جوړونکی»).
هر transformation چې کوډ کوي، باید له دې قواعدو سره وتړل شي او **د قاعدې نوم + منبع** ورسره وښودل شي.

---

## ۴.۰ تعریفونه

| | تعریف |
|---|---|
| **الإعلال** | تغيير **حرف العلة** للتخفيف — بقلبه، أو إسكانه، أو حذفه |
| **الإبدال** | جعل **مُطْلَق حرف** مكان آخر |

**رابطه:**
```
هر إعلال = إبدال دی            (خو عکس یې نه)
دواړه یوځای:  قال، رمى         (قلب حرف علت)
یوازې إبدال:  اصْطَبَر، ادَّكَر  (صاد/دال د تاء پر ځای)
```

**العِوَض ≠ الإبدال:** عوض کولی شي د مُعوَّض عنه **په ځای کې نه** راشي —
لکه د `عِدَة`, `استقامة` تاء (چې د واو/الف عوض ده)، او د `ابن`, `اسم` همزه.

**د أشموني توضیح:** «الإبدال **إزالة**، والقلب **إحالة**. والإحالة لا تكون إلا بين الأشياء **المتماثلة**،
ومن ثَمَّ اختص القلب بحروف العلة والهمزة، لأنها تقاربها بكثرة التغيير.»

### د إبدال درې طبقې

| طبقه | حروف |
|---|---|
| **شائع للإدغام** | ټول حروف پرته له **الف** |
| **نادر** | ح، خ، ع، ق، ض، ذ — `وُكْنة/وُقْنة`, `أغنّ/أخنّ`, `رُبَع/رُبَح`, `خَطَر/غَطَر`, `جَلْد/جَضْد`, `تلعثَم/تلعذَم` |
| **شائع لغير إدغام (۲۲ حرف)** | «لجد صرف شكس أمن طي ثوب عزته» |

> 🔴 **د صرف ضروري حروف — یوازې ۹:**
> ## « هَدَأْتُ مُوطِيًا »
> = **ه · د · أ · ت · م · و · ط · ي · ا**
>
> پاتې یې د صرف لپاره ضروري نه دي (لکه `أصيلال` له `أصيلان`، `الطجع` له `اضطجع`، او د قضاعة «عَجْعَجَة»: `علِجّ` = علِيّ).

## ۴.۱ قلب الواو والياء همزةً

> منبع: `page1_0132`–`0134`

### واجب — ۴ مواضع

#### موضع ۱ — تطرُّف بعد ألف زائدة

| شرط | مثال | اصل |
|---|---|---|
| واو/یاء **آخر کې** وي، **مخکې یې الف زایده** | سَمَاء، بِنَاء | سَمَاو، بِنَاي |
| ❌ نه تطرف | قال، باع، إداوة، هداية | |
| ❌ نه مخکینۍ الف | دَلْو، ظَبْي | |
| ❌ الف زایده نه ده | آية، راية | |

**الف هم ورسره شریکه ده:** `حمراء` ← اصل `حَمْرَى` (لکه سَكْرَى)، مخکې له آخره یې د مد لپاره الف زیاته شوه، بیا وروستۍ همزه شوه.

#### موضع ۲ — عین د اسم فاعل، چې فعل یې معلَّ وي

| مثال | اصل |
|---|---|
| قائل | قاوِل |
| بائع | بايِع |

❌ **استثناء:** `عَيِنَ فهو عاينَ`, `عَوِرَ فهو عاوِر` — ځکه چې په فعل کې یې عین **صحیح** پاتې شوه
(خوف الإلباس بـ`عان`, `عار`)، نو په اسم فاعل کې هم تبعاً صحیح ده.

#### موضع ۳ — بعد ألف مَفَاعِل، که په مفرد کې مدّة زایده وه

| مفرد | جمع | یادونه |
|---|---|---|
| عجوز | عجائز | |
| صحيفة | صحائف | |
| رسالة | رسائل | *(الف هم شریکه)* |
| قِلادة | قلائد | |
| ❌ قَسْوَر | قساوِر | واو مدّة نه ده |
| ❌ مَعِيشة | معايِش | مدّة یې **اصلي** ده |
| ⚠️ مُصيبة | مصائب | **شاذ** — مدّه اصلي وه |
| ⚠️ مَنارة | منائر | **شاذ** |

#### موضع ۴ — ثانيتَي لِينَين بينهما ألف مَفَاعِل

| مفرد | جمع | ډول |
|---|---|---|
| نيِّف | نيائف | یاء + یاء |
| أوَّل | أوائل | واو + واو |
| سيِّد | سيائد | مختلف (اصل: سيود) |

⚠️ **استثناء:** `عَوَاوِر` (د جندل بن المثنى په شعر کې) — ځکه اصل یې `عواوير` و (لکه طواويس)،
او د مفاعیل یاء حذف جایز دی، نو تصحیح شو.

#### ځانګړی حکم د واو — تصدُّر قبل واو

**واو → همزه**، که د کلمې په سر کې وي او ورپسې واو راشي:
- **متحرکه واو** — مطلقاً
- **ساکنه واو** — یوازې که **متأصلة الواوية** وي

| مثال | اصل |
|---|---|
| أواصل | وواصل (جمع واصلة) |
| أواقي | وواقي (جمع واقية) |
| الأولى، الأُوَل | |
| ❌ هَوَوي، نَوَوي | (نسبت هَوىً, نَوَىً) — تصدُّر نشته |
| ❌ وُفِيَ، وُعِدَ (مجهول) | دویمه واو متأصله نه ده |

### جواز — ۲ مواضع (واو → همزه)

| # | شرط | مثالونه |
|---|---|---|
| ۱ | **مضمومة ضمًا لازمًا، غير مشددة** | وُجوه/أُجوه · وُقوت/أُقوت · أدْوُر/أدْؤُر · أنْوُر/أنْؤُر · قَؤُول · صَؤُول |
| | ❌ ضمة الإعراب | هذا دَلْوٌ |
| | ❌ ضمة التقاء الساكنين | `وَلَا تَنسَوُا الْفَضْلَ` |
| | ❌ مشددة | التعوُّذ، التحوُّل |
| ۲ | **مكسورة في أول الكلمة** | وِشاح/إشاح · وِفادة/إفادة · وِسادة/إسادة |

### جواز — یاء → همزه
که یاء **له الف وروسته** او **له یاء مشدَّدې مخکې** وي:
`غاية → غنائيّ`(کذا)، `راية → رائيّ` (په نسبت کې)

**نادر:** همزه له **هاء** بدله شوې په `ماء` کې (دلیل: تصغیر یې `مُوَيْه`، جمع یې `أمواه`).

## ۴.۲ قلب الهمزة ياءً أو واوًا

> منبع: `page1_0135`–`0138`

**یوازې په دوو بابونو کې راځي:**

### باب ۱ — جمع على زنة مَفَاعِل

**شرطونه:**
1. همزه له الف وروسته وي
2. همزه **عارضه** وي (په مفرد کې نه وي) — ❌ `مَرائي` (له مِرآة، همزه یې په مفرد کې شته)
3. لام یې **همزه، واو، یا یاء** وي — ❌ `صحائف`, `عجائز`, `رسائل` (لام یې سالم دی)

**دوه عملیات واجب:**
1. **د همزې کسره → فتحه**
2. **همزه → یاء** (په ۳ مواضعو کې) یا **واو** (په ۱ موضع کې)

| د مفرد لام | همزه اوړي | مثال | مراحل |
|---|---|---|---|
| **همزه** | **یاء** | خطيئة → **خطايا** | خَطَاييء → خطائيء → خطائيَ → خطاءا → **خطايا** (۵ عمله) |
| **یاء اصلیه** | **یاء** | قضية → **قضايا** | قضايي → قضائِيُ → قضاءا → **قضايا** (۴ عمله) |
| **واو چې په مفرد کې یاء شوې** | **یاء** | مَطِيَّة → **مطايا** | مَطايُو → مَطاييُ → مَطاءَيُ → **مطايا** (۵ عمله) |
| **واو ظاهره سالمه** | **واو** | هِرَاوة → **هَرَاوَى** | هَرَائِو → هَرَائي → هَرَاءَيُ → هراءَا → **هَرَاوَى** (۵ عمله) |

**شاذات:** `المَنَائِيا` (قیاس: المنايا) · `خَطَائِئِي` (قیاس: خطاياي) · `هَدَاوَى` (قیاس: هدايا)

> 🔑 **د کوډ لپاره:** دا **step-by-step derivation** ده — د اپلیکېشن د «د اعلال جوړونکی» زړه.
> هر ګام باید جلا وښودل شي، لکه څنګه چې کتاب یې ښیي («بعد خمسة أعمال»).

### باب ۲ — الهمزتان الملتقيتان في كلمة واحدة

**تل دویمه همزه معلَّه کیږي** («لأن الثقل لا يحصل إلا بها»).

| حالت | حکم | مثال |
|---|---|---|
| اوله **متحرکه** + دویمه **ساکنه** | دویمه د لومړۍ **د حرکت له جنسه** اوړي | أَأْمَنْتُ → **آمَنْتُ** ، أُؤْمِنُ → **أُومِنُ** ، إِئْمَانًا → **إِيمَانًا** |
| اوله **ساکنه** + دویمه **متحرکه**، په **عین** کې | اوله په دویمه **ادغام** | سَآّل (مبالغة السؤال) ، لأّال ، رأّاس |
| اوله ساکنه + دویمه متحرکه، په **لام** کې | دویمه **مطلقاً یاء** | قِمَطْر له قرأ → `قَرْأَى` ، سَفَرْجَل → `قَرْأَيَا` |
| **دواړه متحرکې**، په **طرف** کې | دویمه **مطلقاً یاء** | |
| دواړه متحرکې، **نه طرف**، دویمه **مضمومه** | **واو** مطلقاً | |
| دواړه متحرکې، دویمه **مفتوحه**، مخکې یې **فتحه یا ضمه** | **واو** | |
| دواړه متحرکې، دویمه **مفتوحه**، مخکې یې **کسره** | **یاء** | |

**جواز:** `رَأس`, `لُؤْم`, `بِئْر` — همزه پاتې کېدلی شي یا د مخکینې حرکت له جنسه شي.
`وضوء`, `جيء` — همزه پاتې یا مجانس + **ادغام**.

## ۴.۴ قلب الألف والياء واوًا

> منبع: `page1_0143`–`0144`

### الألف → واو
**که مخکې یې ضمه راشي:** `بُويِعَ` · `ضُورِبَ` · `ضُوَيْرِب`

### الياء → واو

| # | شرط | مثال | استثناء |
|---|---|---|---|
| ۱ | **ساکنه، مفرده، مخکې یې ضمه، په غیر جمع کې** | موقِن، مُوسِر، يُوقِن، يُوسِر | ❌ هُيَام (ساکنه نه ده) · ❌ حُيَّض (مفرده نه ده) · ❌ **جمع**: بِيض، هِيم ← دلته **ضمه کسرې ته اوړي واجباً** |
| ۲ | **لام د `فَعُلَ`** | نَهُوَ الرجل، قَضُوَ | |
| ۳ | **کلمه په تاء ختمه شوې چې کلمه پرې جوړه شوې** | له رمي، په وزن مقدُرة → **مَرْمُوَة** | |
| ۴ | **لام د اسم چې په الف موضوع ختم شي** | له رمي، په وزن سَبعان → **رَمُوان** | |
| ۵ | **لام د `فَعْلَى` اسماً (نه صفةً)** | تَقْوَى، شَرْوَى، فَتْوَى | شاذ تصحیح: سَعْيا (مکان)، رَيَّا (رائحة) |
| ۶ | **عین د `فُعْلَى` اسماً** | طُوبَى | |
| ۷ | **عین د `فُعْلَى` صفةً جاریةً مجرى الأسماء (مؤنث أفعل)** | طُوبَى، كُوسَى، خُورَى (< أطيب، أكيس، أخير) | |
| | **که فُعْلَى صفة محضة وي → یاء صحیح پاتې، ضمه کسرې ته اوړي** | `قِسْمَةٌ ضِيزَى` · مِشْيَة حِيكَى | (دا دوه یوازې مسموع دي) |

**بل قول:** که ضمه پاتې شي → یاء واو ته اوړي؛ که ضمه کسره شي → یاء پاتې کیږي:

### د إرشاد الصرف «قاعدة قال وباع» — نور شرطونه

إرشاد الصرف همدا قاعده لږ توپیر سره لیکي (له OCR):

1. په **فاء الکلمه** کې نه وي — ❌ تَيَسَّرَ، توعَّد
2. د **لفیف مقرون** د عین په مقابل کې نه وي — ❌ قَوِيَ، طَوِيَ
3. د **ناقص** په عین کې نه وي — ❌ ارْعَوَى
4. ورپسې **مدّة زایده** نه وي (چې محقق وي، حذف نه شي، ساکنه وي) — ❌ سَواد، بَياض
5. ورپسې **الف التثنية** یا **الف جمع المؤنث السالم** نه وي — ❌ دَعَوا، رَمَيا، عَصَوان، رَحَيان، عَصَوات، رَحَيات
6. ورپسې **یاء النسبة** یا **نون التأكيد** نه وي — ❌ عَصَوِيّ، لَتَدْعُونَّ
7. کلمه په وزن **فَعَلان** یا **فَعْلَى** نه وي، او د **تفاعل** په معنی د افتعال کې نه وي — ❌ حَوَلان، حَيَوان

> 🔑 دا دوه لیستونه یو شی دی په بېلابېلو الفاظو. **کوډ کې دواړه یوځای وګوره** —
> د شذا لیست منظم دی، د إرشاد لیست عملي مثالونه لري.

## ۴.۷ الإعلال بالحذف

> منبع: `page1_0153`–`0154`


### قياسي — درې مسئلې

**مسئله ۱ — د أفْعَلَ همزه**
په مضارع او دواړو وصفونو (اسم فاعل/مفعول) کې **حذف واجب**:
`أكْرَمَ → يُكْرِمُ، نُكْرِمُ، تُكْرِمُ، أُكْرِمُ، مُكْرِم، مُكْرَم`

> **ولې؟** «كراهة اجتماع الهمزتين في المبدوء بهمزة المتكلم (`أُأَكْرِمُ`)، وحُمِل غيره عليه.»
> شاذ: `فإنّهُ أهْلٌ لأنْ يُؤَكْرَمَا`

⚠️ **که د أفعل همزه بدله شوې وي → حذف نه کیږي:**
`هَرَاقَ` (< أراق) — هاء ته · `عَنْهَلَ` (< أنهل) — عین ته
او هاء/عین یې **په ټولو تصاریفو کې مفتوحه** پاتې کیږي.

**مسئله ۲ — د مثال فاء** → وګورئ [`03-sighy-gardan.md`](03-sighy-gardan.md) § المثال

**مسئله ۳ — د مضاعف عین عند إسناده لضمير الرفع المتحرك**

| فعل | حالت | جواز |
|---|---|---|
| **ماضي ثلاثي مکسور العین** | درې وجهه | `ظَلِلْتُ` (اتمام) · `ظِلْتُ` (حذف + نقل حرکت) · `ظَلْتُ` (حذف بې نقله) |
| **ماضي له درېو زیات** | **یوازې اتمام** | `أقررت` (شاذ: `أحَسْتُ` < أحْسَسْتُ) |
| **ماضي ثلاثي مفتوح العین** | **یوازې اتمام** | `حلَلْتُ` (شاذ: `هَمْتُ` < هَمَمْتُ) |
| **مضارع/امر مکسور العین + نون النسوة** | **لومړي دوه وجهه** | `يَقْرِرْنَ` / `يَقِرْنَ` · `اقْرِرْنَ` / `قِرْنَ` |
| | | `وَقَرْنَ فِي بُيُوتِكُنَّ` |
| **که اول المثلین مفتوح وي** | **نقل قلیل** | (قراءة نافع وعاصم: `وَقَرْنَ`) |
