## ۱.۱ د صرف تعریف

**لغةً:** التغيير (بدلون) — لکه «تصريف الرياح» یعنې د بادونو اړول.

**اصطلاحاً — دوه تعریفه:**

| تعریف | متن | څه معنی |
|---|---|---|
| **بالمعنى العَمَلي** | تحويلُ الأصلِ الواحدِ إلى أمثلةٍ مختلفةٍ، لمعانٍ مقصودةٍ لا تحصل إلا بها | یو اصل (مصدر/ماده) په بېلابېلو بڼو اړول د مقصود معنی لپاره |
| **بالمعنى العِلْمي** | علمٌ بأصولٍ يُعرف بها أحوالُ أبنيةِ الكلمةِ التي ليست بإعرابٍ ولا بناءٍ | هغه علم چې د کلمې د جوړښت هغه حالتونه پیژني چې اعراب او بنا نه دي |

> 🔑 **د کوډ لپاره:** «التي ليست بإعرابٍ ولا بناءٍ» — صرف د کلمې **له آخره مخکې** بدلونونه رانغاړي.
> د آخر حرکت (رفع/نصب/جر) د نحو کار دی، نه د صرف. خو د **جزم** او **بنا** له امله چې حرف حذف کیږي
> (لکه `لم يَدْعُ`, `قُلْ`) هغه د صرف کار دی ځکه چې د حرف په ذات کې بدلون راځي.

## ۱.۲ تقسیم الکلمه

| قسم | تعریف | مثال |
|---|---|---|
| **اسم** | ما وُضِع ليَدُلَّ على معنى مستقلّ بالفهم، ليس الزمنُ جزءًا منه | رجل، كتاب |
| **فعل** | ما دلَّ على معنى مستقل، والزمن جزء منه | نصر، يضرب |
| **حرف** | ما دلّ على معنى غير مستقل | من، إلى |

**د صرف موضوع:** یوازې **متمکن اسم** (معرب) او **متصرف فعل**.
حروف، مبني اسمونه (ضمائر، اسماء اشاره، موصولات) او جامد فعلونه (ليس، عسى، نِعْم…) له صرفه بهر دي.

## ۱.۳ الميزان الصَّرفي

د عربي کلمو ډېری برخه درې‌حرفي ده، نو صرفیانو **ف ع ل** د معیار په توګه ونیول:

- لومړی حرف = **فاء الكلمة**
- دویم حرف = **عين الكلمة**
- درېیم حرف = **لام الكلمة**

میزان د موزون **په بڼه** (مصوَّرة بصورة الموزون) لیکل کیږي — یعنې همغه حرکات:

```
قَمَر  → فَعَل        جِمْل → فِعْل        كَرُمَ → فَعُل
```

### د میزان ۴ قاعدې

#### قاعده ۱ — که کلمه له درېو زیاته وي، **او زیاتوالی اصلي وي**
په میزان کې **لام** ورزیاته کړه:

| کلمه | میزان | یادونه |
|---|---|---|
| دَحْرَجَ | فَعْلَلَ | یو لام زیات — په فعل او اسم دواړو کې |
| جَحْمَرِش | فَعْلَلِل | دوه لامه — **یوازې په اسم کې** |

> ولې لام تکراریږي نه فاء یا عین؟ ← «لأنها أقرب» (لام آخر ته نږدې ده، او زیادت په آخر کې وي).

#### قاعده ۲ — که زیاتوالی **د اصلي حرف له تکرار** څخه وي
په میزان کې د هغه **مقابل** حرف تکرار کړه:

| کلمه | میزان | نوم |
|---|---|---|
| قَدَّم | فَعَّل | مضعَّف العين |
| جَلْبَبَ | فَعْلَل | مضعَّف اللام |

> ⚠️ **مهمه:** په میزان کې زیات شوی حرف **پخپله ونه لیکې**.
> `قَدَّمَ` ← ✅ `فَعَّلَ` / ❌ `فَعْدَلَ`

#### قاعده ۳ — که زیاتوالی له **حروف الزيادة** وي
اصلي په اصلي مقابل کړه، زیات حرف **په خپل لفظ** ولیکه:

```
حروف الزيادة = « سَأَلْتُمُونِيهَا »  (ا و ي ن ت س ل م ه ء)
```

| کلمه | میزان |
|---|---|
| قائم | فاعِل |
| تقدَّمَ | تَفَعَّلَ |
| استخرج | اسْتَفْعَلَ |
| مجتهد | مُفْتَعِل |

**استثناء — د افتعال بدله شوې تاء:** د اصل په لحاظ یې تاء ولیکه:
`اضطرَب` ← ✅ `افتعل` / ❌ `افطعل` (رضي یې جواز ورکړی خو مختار لومړی دی)

#### قاعده ۴ — حذف او قلب

| حالت | کلمه | میزان |
|---|---|---|
| **حذف** | قُلْ (اصل: قَوَلَ) | فُلْ |
| **حذف** | قاضٍ | فاعٍ ← (کتاب: `فعٍ`) |
| **حذف** | عِدَة | عِلَة |
| **قلب** | جاه (اصل: وَجْه) | عَفَل |

### د قلب (metathesis) پنځه دلیلونه

| # | دلیل | مثال | میزان |
|---|---|---|---|
| ۱ | **الاشتقاق** — مصدر یې اصل ښیي | ناءَ ← النَّأي | فَلَعَ |
| | | جاه ← وَجْه، وُجْهة | عَفَل |
| | | حادي ← وَحْدة | عالِف |
| ۲ | **التصحيح مع وجود موجب الإعلال** | أيِسَ ← يَئِسَ | عَفِلَ |
| ۳ | **نُدرة الاستعمال** | آرام ← أرآم (جمع رِئم) | أعْفال |
| ۴ | **که قلب نه وي، دوه همزې په آخر کې راځي** | جاء ← اسم فاعل جائي → جاءٍ | فالِع ← فالٍ |
| ۵ | **که قلب نه وي، بې‌سببه منع صرف لازمیږي** | أشياء ← شَيْئَاء (فَعْلاء) | لَفْعَاء |

## ۱.۴ تقسیم الفعل — اووه تقسیمه

### التقسیم ۱ — د زمان له مخې

| قسم | تعریف | علامه |
|---|---|---|
| **ماضي** | حدوث شيء قبل زمن التكلم | تاء الفاعل (`قرأتُ`) یا تاء التأنيث الساکنه (`قرأتْ`) قبلوي |
| **مضارع** | حدوث شيء في زمن التكلم أو بعده | له `لم` وروسته راځي؛ په «أنَيْتُ» (أ ن ي ت) پیل کیږي |
| **أمر** | طلب حصول شيء بعد زمن التكلم | نون التوکید + یاء المخاطبه قبلوي، له طلب سره |

**د مضارع د حروفو تفصیل:**

| حرف | څوک |
|---|---|
| **أ** (همزه) | متکلم وحده — `أنا أقرأ` |
| **ن** | متکلم مع الغیر / معظِّم نفسه — `نحن نقرأ` |
| **ي** | غائب مذکر (مطلق) + **جمع الغائبة** — `يقرأ`، `النسوة يقرأن` |
| **ت** | مخاطب (مطلق) + مفرد الغائبة + مثناها — `تقرأ`، `فاطمة تقرأ`، `الهندان تقرآن` |

**د مضارع د زمان تعیین:**
- **حال** ته یې ټاکي: لام الابتداء، «لا» او «ما» النافيتان
- **استقبال** ته یې ټاکي: سوف، لن، أن، إن

---

### التقسیم ۲ — صحیح / معتل

```
الفعل
├── صحیح  (اصول یې له حروف علت خالي)
│   ├── سالم     — له علت، همزې او تضعیف خالي  → ضرب، نصر، قعد، جلس
│   ├── مضعَّف   (الأصمّ)
│   │   ├── مضعَّف ثلاثي   — عین او لام یې یو جنس  → فَرَّ، مَدَّ، امتدَّ، استمدَّ
│   │   └── مضعَّف رباعي   — فاء=لام۱ او عین=لام۲  → زلزل، عسعس، قلقل
│   └── مهموز   — یو اصل یې همزه وي
│       ├── مهموز الفاء  → أخذ
│       ├── مهموز العين  → سأل
│       └── مهموز اللام  → قرأ
└── معتل  (یو اصل یې حرف علت وي)
    ├── مثال    — فاء یې معتله  → وَعَدَ، يَسَرَ
    ├── أجوف   — عین یې معتله  → قال، باع     (= ذو الثلاثة)
    ├── ناقص   — لام یې معتله  → غزا، رمى     (= ذو الأربعة)
    └── لفيف
        ├── مفروق  — فاء + لام معتله (صحیح یې منځ کې فارق دی)  → وَفَى، وَقَى
        └── مقرون  — عین + لام معتله (دواړه یوځای)             → طَوَى، رَوَى
```

**د نومونو تعلیل** (د کوډ په UI کې ښه ده چې ښکاره شي):

| نوم | ولې |
|---|---|
| مثال | «يُماثِل الصحيح في عدم إعلال ماضيه» — ماضي یې لکه صحیح دی |
| أجوف | «لخلوّ جوفه» — منځ یې تش دی |
| ذو الثلاثة | له تاء الفاعل سره درې حروف کیږي: `قُلْتُ`, `بِعْتُ` |
| ناقص | «لنقصانه بحذف آخره في بعض التصاريف» — `غَزَتْ`, `رَمَتْ` |
| ذو الأربعة | له تاء الفاعل سره څلور حروف: `غَزَوْتُ`, `رَمَيْتُ` |
| مفروق | صحیح حرف د دوو علت حروفو ترمنځ فرق دی |
| مقرون | دواړه علت حروف سره نږدې دي |

**د حروف علت درجې:**

| ډول | شرط | مثال |
|---|---|---|
| **حرف علت** | ا، و، ي | مطلقاً |
| **لِين** | ساکن وي او مخکې یې فتحه وي | ثَوْب، سَيْف |
| **مدّ** | لِین وي او مخکینی حرکت ورسره **مجانس** وي | قال، يقُول، قِيلا |

> **الف** هېڅکله له دې درېواړو نه جلا کیږي — تل ساکنه او مخکې یې فتحه وي.

> ⚠️ دا ټول تقسیمات **په اسم کې هم** جاري دي: شمس (سالم)، وجه (مثال)، قول (أجوف)، ظَبْي (ناقص)، جَوّ/حَيّ (مقرون)، أمر (مهموز الفاء)، بئر (مهموز العين)، نبأ (مهموز اللام)، حَدّ (مضاعف)، بلبل (رباعي مضاعف).

### مضارع له ماضي څخه

```
۱. په اول کې د «أنَيْتُ» یو حرف زیات کړه:
     - رباعي        → مضموم    (يُدحرِج)
     - نور ټول      → مفتوح    (يَكتب، يَنطلق، يَستغفر)

۲. که ماضي ثلاثي وي:
     - فاء ساکنه کړه
     - عین ته ضمه / فتحه / کسره ورکړه — «حسبما يقتضيه نصُّ اللغة» (سماعي!)
       → يَنصُر، يَفتَح، يَضرِب

۳. که ثلاثي نه وي:
     - که په زیاته تاء پیل شوی وي → همداسې پرېږده  (يَتَشارَك، يَتَعَلَّم، يَتَدحرج)
     - که نه → ما قبل الآخر مکسور کړه           (يُعَظِّم، يُقاتِل)
     - په اول کې زیاته همزه **حذف کړه**          (أكرم → يُكرِم، استخرج → يَستخرِج)
```

### امر له مضارع څخه

```
۱. حرف المضارعة حذف کړه:   عَظِّمْ، تَشاركْ، تَعَلَّمْ
۲. که پاتې برخه په ساکن پیل شي → مخکې یې همزة الوصل زیاته کړه:
     اسرُقْ، افتَحْ، اضرِبْ، أكرِمْ*، انطلِقْ، استغفِرْ

   * أكرِمْ ← دا همزة القطع ده (له أفعل څخه)، نه همزة الوصل
```

> 🔑 **د کوډ لپاره:** د عین المضارع حرکت (ضمه/فتحه/کسره) **له قاعدې څخه نه جوړیږي — سماعي دی**.
> شذا العرف: «كون الثلاثي على وزن معين من الأوزان الستة المتقدمة **سماعيّ**، فلا يعتمد في معرفتها على قاعدة».
> نو د هر ثلاثي مجرد فعل لپاره **باب باید په ډاټابیس کې ثبت شي**، اټکل یې مه کوه.
