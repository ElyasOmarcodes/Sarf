## ۵.۱ تعریف

**لغةً:** الإدخال.

**اصطلاحاً:** «الإتيان بحرفين — **ساكن فمتحرك** — من مَخْرج واحد بلا فصل بينهما،
بحيث يرتفع اللسان وينحطّ بهما **دفعة واحدة**.»

**تلفظ:** الإدغام (بسکون الدال — کوفیان) / الإدّغام (بشدها — بصریان، سیبویه یې کاروي)

**دایره:** ټول حروف پرته له **الف اللينة**؛ په متماثلینو او متقاربینو کې، په یوه کلمه او په دوو کلمو کې.

```
الإدغام
├── ممتنع
├── واجب
└── جائز
```

## ۵.۳ الإدغام الواجب

### حالت أ — اول ساکن، دویم متحرک
**واجب** — که اول یې مدّ نه وي او له فاء جلا شوې همزه نه وي:
`جدّ` · `حظّ` · `سَآّل` · `رَآّس` (بوزن فَعّال)

### حالت ب — دواړه متحرک: **۱۱ شرطه**

| # | شرط | که نه وي |
|---|---|---|
| ۱ | **په یوه کلمه کې** وي | په دوو کلمو کې → **جایز** (نه واجب): `جعلَ لَكم` |
| ۲ | یو یې **متصدر** نه وي | ❌ دَدَن (اللهو) |
| ۳ | په **مدغم** پورې نه وي نښتی | ❌ جُسَّس (جمع جاسّ) |
| ۴ | په **ملحق** وزن کې نه وي | ❌ قَرْدَد (ملحق بجعفر) · جَلْبَب (بدحرج) · اقعنسَس (باحرنجم) |
| ۵ | په اسم کې په وزن **فَعَل** نه وي | ❌ طَلَل |
| ۶ | په اسم کې په وزن **فُعُل** نه وي | ❌ ذُلُل (جمع ذَلول) |
| ۷ | په اسم کې په وزن **فِعَل** نه وي | ❌ لِمَم (جمع لِمَّة) |
| ۸ | په اسم کې په وزن **فُعَل** نه وي | ❌ دُرَر (جمع دُرَّة) |
| ۹ | یو یې **عارض** نه وي | ❌ اخْصُصْ أبِي · اكْفُفِ الشرَّ |
| ۱۰ | **دوه یاءې** نه وي چې دویمه یې لازماً متحرکه وي | ❌ حَيِيَ · عَيِيَ |
| ۱۱ | **دوه تاءې په افتعل** کې نه وي | ❌ استَتَرَ · اقتَتَلَ |

> ⚠️ **په وروستیو درېو (۹، ۱۰، ۱۱) کې ادغام او فک دواړه جایز دي.**

## ۵.۴ الإدغام الجائز — درې نورې صورتې

### ۱. لومړۍ تاء له دوو زیاتو تاءو څخه د مضارع په سر کې

`تَتَجَلَّى` → **`اتَّجَلَّى`** · `تَتَعَلَّم` → **`اتَّعَلَّم`**

> 🔑 **که ادغام وکړې → په سر کې همزة الوصل زیاتوې** (د نطق د امکان لپاره).
> ابن هشام یې په «التوضيح» کې پر ابن مالک رد کړی («د مضارع په سر کې همزة الوصل نشته»)،
> **خو دا په عربي کې حجت دی.**

**بېلګه:** له `استَتَر`, `اقتَتَل` → `يُسَتِّر سِتَّارًا` (د لومړۍ تاء حرکت فاء ته نقل، همزة الوصل غورځي — **خماسي دی**)
⚠️ توپیر یې له `سَتَّر` (لکه فعَّل) سره، چې مصدر یې **التفعیل** دی.

**که په ابتداء کې تخفیف غواړې → دویمه تاء حذف کړه:**
`نَارًا تَلَظَّى` (< تتلظى) · `كُنْتُمْ تَمَنَّوْنَ` (< تتمنون)
*(بزّي یې په ادغام لولي: `تَلَّظَّى`, `كُنتُمُ تَّمَنَّوْنَ`, `ولا تَّفرقوا`)*

**نون هم:** `وَكَذَلِكَ نُنْجِي الْمُؤْمِنِينَ` — عاصم (شعبه): `نُجِّي` (دویم نون حذف + ادغام)

### ۲ و ۳. مضارع مجزوم بالسکون او امر مبني علیه

| لهجه | حکم | مثال |
|---|---|---|
| **حجازيون** | **فك** | `وَمَنْ يَرْتَدِدْ مِنْكُمْ عَنْ دِينِهِ` · `وَاغْضُضْ مِنْ صَوْتِكَ` |
| **تميميون** | **إدغام** | `فَغُضَّ الطرْفَ إنكَ مِنْ نُمَيْرٍ` |

### دوه استثناوې (التزام)

| کلمه | التزام | ولې |
|---|---|---|
| **أفْعَل في التعجب** | **فك واجب** | `أحبِبْ بزيد` · `أشْدِدْ بِبَياضِ وجهِ المتقين` |
| **هَلُمَّ** | **إدغام واجب** + آخر یې **مفتوح** | «لثقلها بالتركيب» |
| | ❌ ضم للاتباع او کسر للتخلص (لکه رُدَّ) نه جایز | `هَلُمَّ إِلَيْنَا` · `هَلُمَّ شُهَدَاءَكُمْ` |

## ۵.۶ إدغام المتقاربين — مخارج او صفات

> منبع: `page1_0160`–`0162`

### ۱۴ مخرجه

| # | مخرج | حروف |
|---|---|---|
| ۱ | أقصى الحلق | ا، ء، هـ |

> 🔑 د **ذلاقت** فایده: «لخفة أحرفها **لا يخلو رُباعيّ أو خُماسيّ** — لثقلهما — **من أحدها إلا نادرًا**»
> (نادر: `العَسَد` = الذهب، `الزَّهْزَقة` = شدة الضحك)
> ← دا د اپلیکېشن لپاره یو ښه **validation rule** دی: رباعي/خماسي کلمه چې له «مر بنفل» یو حرف هم نه لري → مشکوکه ده.

### د متقاربینو د ادغام قاعده
**«قَلْب الأول إلى الثاني، لا العكس»** — پرته له هغه چې حال یې وغواړي: `ادَّكَرَ`, `اذَّكَرَ`

### درې احکام

#### الوجوب

| حالت | حروف |
|---|---|
| **لام التعريف** + **حروف شمسية** | ت ث د ذ ر ز س ش ص ض ط ظ ل ن (۱۴) |
| **لام ساکنه** (غیر لام التعریف) + **راء** | `بَلْ رَفَعَهُ اللَّهُ` |
| **نون ساکنه** + ۶ حروف | ی ن م و (**بغُنّة**) + ل ر (**بلا غُنّة**) |

**د نون الساکنة پنځه حالتونه:**
| حالت | تفصیل |
|---|---|
| ۱. **إظهار** | مع حروف الحلق |
| ۲. **إدغام** | مع «يرملون» |
| ۳. **إقلاب** | مع الباء (نون → میم) |
| ۴. **إخفاء** | مع الباقي |
| *(۵. الغُنّة د ادغام یوه فرعي حالت)* | |

#### الامتناع
❌ **د دې حروفو ادغام په متقاربینو کې ممتنع دی:**

## « ضَوِيَ مِشْفَر »  =  ض · و · ي · م · ش · ف · ر

**ولې؟** ځکه چې د ادغام په صورت کې د دوی ځانګړې صفت له منځه ځي:

| حرف | صفت چې ورکیږي |
|---|---|
| ض | **استطالة** |
| و، ي | **لِين** |
| م | **غُنّة** |
| ش، ف | **تفشّي** |
| ر | **تكرار** |

> ⚠️ `سيِّد`, `مَهْدِيّ` رد نه دی — ځکه چې **إعلال** یې مثلان جوړ کړي دي (نه متقاربین).

#### الجواز
پاتې ټول — لکه:
- نون **متحرکه** په «يرملون» کې
- ت، ث، د، ذ، ط یو په بل کې، یا په ز، س، ص کې:
  `سكَتَّ ثَّابِت` · `سكت دّارم` · `لبثَ تَّاجر` · `حقدَ تّاجر` …

## ۵.۷ 🔴 التقاء الساكنين

> منبع: `page1_0163`–`0166`

**قاعده:** که دوه ساکنه سره ولګیږي (په یوه یا دوو کلمو کې) → **باید ترې خلاص شو**،
یا په **حذف اول** یا په **تحریک**.

### الحذف

| حالت | حکم | مثال |
|---|---|---|
| **په یوه کلمه** کې، اول یې **مدّة** | **لفظاً او خطاً حذف** | قُلْ · بِعْ · خَفْ |
| | | أنتم تَغْزُونَ · تَقْضُونَ · لَتَغْزُنَّ · لَتَرْمُنَّ |
| | | أنتِ تَرْمِينَ · تَغْزِينَ · لَتَرْمِنَّ · لَتَغْزِنَّ |
| **په دوو کلمو** کې، اول یې **مدّة** | **لفظاً حذف، خطاً پاتې** | يغزو الجيشُ · يرمي الرجلُ · `رَكْعَتَا الفَجْرِ` · `وَأُولِي الْأَمْرِ مِنْكُمْ` |
| **نون التوکید الخفیفة** | حذف | (وګورئ [`03`](03-sighy-gardan.md)) |
| **تنوین العلم الموصوف بابنٍ** | حذف | محمدُ بنُ عبدِ الله |

### التحريك

| حرکت | حالت | مثال |
|---|---|---|
| **کسره** | **اصل** او **اکثر** | |
| **ضمه واجبه** | ۱. امر المضعَّف + هاء الغائب، او مضارع مجزوم | رُدَّهُ · لم يَرُدَّهُ *(کوفیان فتح او کسر هم جایز ګڼي)* |
| | ۲. **میم جماعة الذکور** چې په **مضموم ضمیر** پورې نښتې وي | `كُتِبَ عَلَيْكُمُ الصِّيَامُ` · `لَهُمُ الْبُشْرَى` |
| **ضم راجح** | **واو الجماعة** چې مخکې یې فتحه وي | اخشَوُا الله · `وَلَا تَنسَوُا الْفَضْلَ` («لخفة الضمة على الواو») |
| **ضم = کسر** | میم الجماعة چې په **مکسور ضمیر** پورې نښتې | بهمُ اليوم / بهمِ اليوم |
| | چیرې چې د دویم ساکن راتلونکی حرف **اصلاً مضموم** وي (که څه هم د مناسبت لپاره مکسور شوی) | `قالتِ اخْرُج` · `قالتِ اغزِي` · `أَنِ اقْتُلُوا` · `أَوِ اخْرُجُوا` |
| **فتحه واجبه** | ۱. **تاء التأنيث** + الف الاثنین | `قَالَتَا` |
| | ۲. **نون «مِنْ»** + `أل` | `مِنَ اللهِ` · `مِنَ الكتاب` *(بې «أل» کسر اکثر: `مِنِ ابنك`)* |
| | ۳. امر المضعَّف مضموم العین + **ضمیر غائبه** | رُدَّها · لم يَرُدَّها |
| **فتح راجح** | | `الم، اللهُ` |
| **فتح = کسر** | مضموم العین له امر المضعَّف او مضارع یې (پرته له مخکینیو) | |

### ⚡ درې ځایه چې التقاء الساکنین **مغتفر** (بښل شوی) دی

| # | حالت | مثال |
|---|---|---|
| ۱ | اول یې **حرف لین** وي، دویم یې **په مثل کې مدغم**، دواړه په **یوه کلمه** | `وَلَا الضَّالِّينَ` · مادّة · دابّة · خُوَيْصَّة · تُمُودَّ الحبلُ |
| ۲ | هغه کلمې چې **سرد** (لیست کول) یې قصد وي | جِيمْ · مِيمْ · قَافْ · وَاوْ |
| ۳ | هغه کلمې چې پرې **وقف** شوی وي | قالْ · زيدْ · ثوْبْ · بكْرْ · عَمْرْو |

> 🔑 **د وقف نکته:** که ما قبل الآخر **صحیح** وي → التقاء ساکنین **ظاهري** دی
> (په حقیقت کې صحیح حرف په **کسرة مختلسة جداً** متحرک دی).
> که ما قبل الآخر **حرف لین** وي → التقاء ساکنین **حقیقي** دی.
>
> **د لین د خفت ترتیب په وقف کې:** الف → واو/یاء (مدّین) → لینان بې مدّه (ثَوْب، بَيْت)
