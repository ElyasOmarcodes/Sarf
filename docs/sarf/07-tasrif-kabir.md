# ۷. 🔴 التصريف الكبير — د باب اول بشپړ ګردان

> منبع: **إرشاد الصرف (فارسي اصل)** — مولانا عبد الكريم القلاتوالي، مخ ۴–۲۳
> فایل: `sources/irshad-al-sarf-farsi/irshad-al-sarf-farsi.pdf`

🔴 **دا فایل د اپلیکېشن د ډاټا ماډل بشپړ نقشه ده.**
د فارسي اصل نسخه هرې صیغې ته **درې څیزونه** ورکوي چې عربي تعریب کې نشته:

```
┌─────────────┬────────────────────────────────┬──────────────────────────────────────┐
│   صیغه      │            معنی                 │              نوم                     │
│  ضَرَبَ      │  زد آن یک مرد در زمان گذشته      │  صیغه واحد مذکر غائب، فعل ماضی معلوم │
│             │  (وې واهه هغه یو سړي)           │  ثلاثی مجرد صحیح از باب فَعَلَ يَفْعِلُ  │
└─────────────┴────────────────────────────────┴──────────────────────────────────────┘
```

**د اپلیکېشن هره کرښه باید همدا درې برخې ولري.**

## ۷.۰ ⚠️ د اصطلاحاتو توپیر — کوم وکاروو؟

| مفهوم | **فارسي اصل** | عربي تعریب |
|---|---|---|
| ۲-پرسون | **مخاطب** / مخاطبین / مخاطبة / مخاطبتین / مخاطبات | حاضر |
| ۱-پرسون مفرد | **واحد متکلم مشترک** | واحد المتكلم |
| ۱-پرسون جمع | **جمع متکلم مع الغیر مشترک** | جمع المتكلم |
| مؤنث مفرد | **واحده مؤنث** (په تاء) | الواحد المؤنث |

> 🔑 **پرېکړه:** اپلیکېشن دې **د فارسي اصل اصطلاحات** وکاروي — **مخاطب**، **مشترک**، **مع الغیر**.
> دا هغه دي چې د برصغیر/افغانستان طالب العلم ورسره بلد دی، او دا اصلي متن دی؛
> عربي تعریب یې وروسته ترجمه ده.
>
> ⚠️ **«مشترک» یوه مهمه مفهومي نکته ده:** متکلم صیغه د مذکر او مؤنث ترمنځ **ګډه** ده،
> نو هغې ته `gender: mushtarak` ورکړه، نه `gender: mudhakkar`.

## ۷.۳ 🔴 د صیغو شمېر ولې بدلیږي — دا **قاعده** ده، نه استثناء

دا د ګردان انجن لپاره **derivable rule** دی:

### أ. امر او نهي حاضر → ۶ صیغې
یوازې **مخاطب** (۷–۱۲). غائب او متکلم یې نه لري ځکه چې امر مستقیم خطاب دی.

### ب. امر او نهي غائب → ۸ صیغې
**غائب ۶** (۱–۶) + **متکلم ۲** (۱۳–۱۴) = ۸. مخاطب یې نشته (هغه بېل باب لري).

### ج. 🔑 نون **خفیفه** → صیغې راکمیږي

د شذا العرف قاعده ([`03-sighy-gardan.md`](03-sighy-gardan.md) § نون التوکید) وايي:
**نون خفیفه له الف وروسته نه راځي** (لالتقاء الساكنين على غير حدّه).

دا کتاب همدا قاعده **په عمل کې** ښیي — د خفیفې جدولونه لنډ دي:

| مجموعه | ثقیله | **خفیفه** | کوم صیغې غورځي؟ |
|---|---|---|---|
| **حاضر** (۶) | ۶ | **۳** | ❌ تثنیه مذکر (الف) · ❌ تثنیه مؤنث (الف) · ❌ جمع مؤنث (نون نسوه) |
| | | ✅ پاتې: واحد مذکر · جمع مذکر · واحده مؤنث | |
| **غائب** (۸) | ۸ | **۵** | ❌ تثنیه مذکر · ❌ تثنیه مؤنث · ❌ جمع مؤنث |
| | | ✅ پاتې: واحد مذکر · جمع مذکر · واحده مؤنث · واحد متکلم · جمع متکلم | |

```dart
/// نون خفیفه یوازې هغو صیغو ته راځي چې نه الف لري او نه نون النسوة
bool acceptsNunKhafifa(SighaKey k) =>
    k.number != Number.tathniya &&                       // الف التثنية
    !(k.number == Number.jam && k.gender == Gender.muannath); // نون النسوة
```

> ✅ **دا د دواړو کتابونو ترمنځ تصدیق دی:** شذا العرف قاعده وايي، إرشاد الصرف یې په جدول کې تطبیقوي.

فارسي معنی: «یک آله زدن» / «دو آله زدن» / «همه آلات زدن» / «یک آله اندک زدن»
پښتو: «د وهلو یو وسیله» / «دوه وسیلې» / «ټولې وسیلې» / «د وهلو یوه وړه وسیله»

> 🔑 دا **درې‌کچیز** جوړښت د اپلیکېشن لپاره ښه ښکارېدونکې ډاټا ده —
> د اسم آله لپاره یو `size: sughra | wusta | kubra` فیلډ لازم دی.

### اسم ظرف (زمان او مکان) — ۴ صیغې

| صیغه | فارسي معنی |
|---|---|
| **مَضْرِبٌ** | یک جا **یا** یک وقت زدن |
| **مَضْرِبَانِ** | دو جا یا دو وقت زدن |
| **مَضَارِبُ** | همه جا یا همه وقت زدن (جمع مکسر) |
| **مُضَيْرِبٌ** | یک جا یا یک وقت **اندک** زدن (مصغر) |

> ⚠️ **زمان او مکان دواړه یوه صیغه ده** — بېل نه دي. UI کې دې «د وهلو ځای یا وخت» ولیکل شي.

### اسم تفضیل — ۵ + ۵

**مذکر:** أَضْرَبُ · أَضْرَبَانِ · أَضْرَبُونَ (جمع سالم) · أَضَارِبُ (جمع مکسر) · أُضَيْرِبُ (مصغر)
فارسي: «یک مرد بسیار زننده» / «یک مردک بهترک زننده» (مصغر)

**مؤنث:** ضُرْبَى · ضُرْبَيَانِ · ضُرْبَيَاتٌ (جمع سالم) · ضُرَبُ (جمع مکسر) · ضُرَيْبَى (مصغر)

### فعل تعجب — ۳ صیغې

| صیغه | فارسي معنی |
|---|---|
| **مَا أَضْرَبَهُ** | چه خوش زد آن یک مرد در زمان گذشته |
| **أَضْرِبْ بِهِ** | چه خوش زد … |
| **وَضَرُبَ** | چه خوش زد … |

پښتو: «څومره ښه یې وواهه!»

### اسم مبالغه — اوزان

| وزن | مثال | وزن | مثال |
|---|---|---|---|
| **فَعَّالٌ** | غَفَّارٌ | **فَعُّولٌ** | قُدُّوسٌ |
| **فَعُولٌ** | غَفُورٌ · صَبُورٌ · شَكُورٌ | **فَعِيلٌ** | رَحِيمٌ |
| **فَعَّالَةٌ** | عَلَّامَةٌ | **فَعْلَانُ** | رَحْمَانُ |

> 🔑 **قاعده:** «بدانکه **اکثر در صیغه مبالغه مذکر و مؤنث یکسان آید**،
> چنانچه `عَلَّامَة` برای مذکر و مؤنث یکسان آید.»
> ← د اسم مبالغې لپاره `gender: mushtarak` default دی.

### صفت مشبهه — ۱۰ صیغې (لکه اسم فاعل)

مثال یې له **باب کرم** (فَعُلَ يَفْعُلُ) دی: **الشَّرَفُ** = بزرگ شدن

شَرِيفٌ · شَرِيفَانِ · شَرِيفُونَ · **شُرَفَاءُ** (جمع مکسر؛ بدلونه: شُرَفَانٌ · شِرْفَانٌ · شِرَافٌ · شُرُفٌ · أَشْرَافٌ · أَشْرِفَاءُ · أَشْرِفَةٌ) ·
شَرِيفَةٌ · شَرِيفَتَانِ · شَرِيفَاتٌ · **شَرَائِفُ** (جمع مؤنث مکسر) · شُرَيِّفٌ (مصغر مذکر) · شُرَيِّفَةٌ (مصغر مؤنث)

## ۷.۵ صرف صغیر — د باب لنډیز

مخکې له صرف کبیره، کتاب **صرف صغیر** ورکوي — د ټول باب په یوه کرښه کې لنډیز:

> چون **الضَّرْبُ** (زدن):
> ضَرَبَ يَضْرِبُ ضَرْبًا فَهُوَ ضَارِبٌ وَذَاكَ مَضْرُوبٌ · وَضُرِبَ يُضْرَبُ ضَرْبًا ·
> لَمْ يَضْرِبْ لَمْ يُضْرَبْ · لَا يَضْرِبُ لَا يُضْرَبُ · لَنْ يَضْرِبَ لَنْ يُضْرَبَ ·
> الأَمْرُ مِنْهُ اضْرِبْ لِتُضْرَبْ لِيَضْرِبْ لِيُضْرَبْ ·
> وَالنَّهْيُ عَنْهُ لَا تَضْرِبْ لَا تُضْرَبْ لَا يَضْرِبْ لَا يُضْرَبْ ·
> الظَّرْفُ مِنْهُ مَضْرِبٌ · وَالآلَةُ مِنْهُ مِضْرَبٌ مِضْرَبَةٌ مِضْرَابٌ ·
> وَفِعْلُ التَّفْضِيلِ المُذَكَّرُ مِنْهُ أَضْرَبُ وَالمُؤَنَّثُ مِنْهُ ضُرْبَى ·
> وَفِعْلُ التَّعَجُّبِ مِنْهُ مَا أَضْرَبَهُ وَأَضْرِبْ بِهِ وَضَرُبَ

> 🔑 **د اپلیکېشن لپاره:** «صرف صغیر» یوه ښه **لنډه لیدنه (summary card)** ده —
> کاروونکی لومړی دا ویني، بیا په هرې برخې کلیک کوي او صرف کبیر ورته پرانیزي.
> دا د طالب العلم د حفظ کولو طبیعي ترتیب دی.
