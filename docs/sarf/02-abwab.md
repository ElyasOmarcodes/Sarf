## ۲.۰ عمومي جوړښت

```
الفعل
├── مجرَّد  (ټول حروف یې اصلي، پرته له علته یو هم نه غورځي)
│   ├── ثلاثي مجرد   →  ۶ بابه
│   └── رباعي مجرد   →  ۱ باب  (فَعْلَلَ)
└── مزيد   (یو یا زیات حروف پرې زیات شوي)
    ├── مزيد الثلاثي →  ۱۲ باب  (۳ + ۵ + ۴)
    └── مزيد الرباعي →  ۳ بابه   (۱ + ۲)
```

**د فعل حداکثر اوږدوالی: ۶ حروف.** (اسم تر ۷ رسیږي — «لثقل الفعل وخفة الاسم»)

**په مادې کې څلور قسمه:** ثلاثي، رباعي، خماسي، سداسي.
**په هیئت (حرکات/سکنات) کې: ۳۷ بابه.**

**د إرشاد الصرف ټولګه: ۴۰ بابه** = ۶ (ثلاثي مجرد) + ۱۲ (ثلاثي مزید) + ۱ (رباعي مجرد) + ۳ (رباعي مزید) + ۱۸ (ملحقات)

### د هر باب تفصیل

#### باب ضَرَبَ يَضْرِبُ (فَعَلَ يَفْعِلُ) — إرشاد ۱ / شذا ۲
مثالونه: ضَرَبَ يضْرِب، جَلَسَ يَجْلِسُ، وَعَدَ يَعِد، باع يبيع، رَمى يرمِي، وَقى يقِي، طَوَى يطْوي، فرَّ يفِرُّ، أتى يأتي، جاء يجيء، هَنَأ يهنيء، أوى يَأوي، وَأى يَئي

**ضابطه:** که `فَعَلَ` مفتوح العين وي او **اوله یې همزه یا واو** وي → غالباً همدا باب.
`أسَر يأسِر`، `أتَى يأتِي`، `وعد يعِد`، `وزَن يزِن`
(خلاف الغالب: أخَذ، أكَل، وَهَل)

که **مضاعف او لازم** وي → غالباً همدا باب: `خفَّ يَخِفُّ`, `شذّ يشِذ`

#### باب نَصَرَ يَنْصُرُ (فَعَلَ يَفْعُلُ) — إرشاد ۲ / شذا ۱
مثالونه: نَصَرَ يَنْصُر، قَعَدَ يَقْعُدُ، أخَذَ يأخُذُ، بَرأ يَبْرُؤ، قال يقُول، غَزَا يغْزو، مَرَّ يَمُرُّ

**ضابطه:** که **مضاعف او متعدي** وي → غالباً همدا باب: `مَدّه يَمُدُّه`, `صدّه يصُدُّه`

#### باب سَمِعَ يَسْمَعُ / فَرِحَ يَفْرَحُ (فَعِلَ يَفْعَلُ) — إرشاد ۳ / شذا ۴
مثالونه: فرِحَ يفرَح، علِم يعلَم، وجِل يوجَل، يَبِسَ ييبَس، خاف يَخاف، هاب يَهاب، غَيِدَ يَغْيَدُ، عَوِر يَعْوَر، رَضي يرضىَ، قَوِي يقْوى، وَجِيَ يوْجَى، عَضَّ يَعضّ، أمِن يأمَن، سَئِم يَسْأم، صَدِئ يَصْدأ

**🔑 د معنی ضابطې** — دا باب دې معناوو ته راځي:

| معنی | مثالونه |
|---|---|
| الفرح وتوابعه | فرِح، طرِب، بَطِر، أشِر، غَضِب، حزِن |
| الامتلاء والخُلُوّ | شبِع، رَوِي، سكِر / عطِش، ظمِئ، صَدِي، هَيِم |
| الألوان | حَمِر، سَوِد |
| العيوب | عَوِر، عَمِش، جَهِر |
| الخِلق الظاهرة (د غزل لپاره) | غَيِد، هَيِف، لَمِي |

#### باب فَتَحَ يَفْتَحُ (فَعَلَ يَفْعَلُ) — إرشاد ۴ / شذا ۳
مثالونه: فتَح يفتَح، ذَهب يذْهَب، سَعى يَسْعى، وَضَع يضع، يَفَع يَيْفَعُ، وَهَل يَوْهَل، ألَهَ يألَه، سَأل يَسْأل، قَرأ يقرأُ

> 🔴 **قاعده:** «كل ما كانت عينهُ مفتوحةً في الماضي والمضارع، فهو **حَلْقيُّ العين أو اللام**.
> ولیس کل ما کان حلقیاً مفتوحاً فیهما.»
>
> **حروف الحلق (۶):** ء، هـ، ح، خ، ع، غ

**استثناءات (شاذ یا غیر فصیح):**
- `أبَى يأبَى`, `هَلَكَ يهْلَك` (په یوه لهجه) — شاذ
- `رَكَن يرْكن`, `قَلَى يَقْلى` — د لهجو تداخل، **غیر فصیح** (فصیح: کسر العین)
- `بَقَى يبقَى` — د طيِّئ لهجه (اصل: بَقِيَ)

#### باب حَسِبَ يَحْسِبُ (فَعِلَ يَفْعِلُ) — إرشاد ۵ / شذا ۶
مثالونه: حسِب يحسِب، نعِم ينعِم
**«قلیل في الصحیح، کثیر في المعتل»**

#### باب كَرُمَ يَكْرُمُ (فَعُلَ يَفْعُلُ) — إرشاد ۶ / شذا ۵
مثالونه: شرُف يشرُف، حسُن يحْسُن، وسُم يوسُم، يَمُن ييمُن، أسُل يأسُل، لؤُم يلؤُم، جرُؤ يجرُؤ، سَرُوَ يَسْرُو

**🔴 ځانګړي حکمونه:**
1. **تل لازم دی** — «فلا تكون إلا لازمة»
   (`رَحُبَتْك الدارُ` توسع دی؛ اصل: `رَحُبَتْ بك الدارُ`)
2. **د خِلقي (دایمي) وصفونو لپاره** — «الأوصاف الخِلْقية، وهي التي لها مُكْث»
3. **هر ثلاثي فعل دې باب ته اړولی شې** — د دې لپاره چې معنی یې «کالغریزة» (طبیعت) شي
4. کله د **تعجب** لپاره کارول کیږي (بیا له حدثه جلا کیږي)

**نادر مثالونه:**
- یائي العین: یوازې `هَيُؤَ` (صار ذا هيئة)
- یائي اللام (متصرف): یوازې `نَهُوَ` (له النُّهية = عقل)
- مضاعف: قلیل — `شَرُرْت` (مثلث الراء)، `لَبُبْت` (بضم/کسر العین؛ مضارع یې یوازې `تَلَبُّ` بفتح العین)

- **ناقص:** د لومړي او دویم باب لپاره همغه شرط (واوي/یائي).
- **لفيف مقرون:** یائي العین واللام یوازې په دوو کلمو کې راځي، دواړه له باب فرح: **`عَيِيَ`** او **`حَيِيَ`**.

### د مغالبې (غلبې) فعل

که فعل د **غلبې** لپاره جوړ شي (سابقني زيد فسبقتُه):
