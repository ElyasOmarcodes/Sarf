## 🔴 د کوډ لپاره بنسټیز قواعد

دا هغه پرېکړې دي چې له کتابونو راوتلي او **باید په ټول کوډبېس کې ورته پاتې شي**:

### ۱. سماعي ≠ قیاسي — دا توپیر باید په ډاټا ماډل کې ښکاره وي

| څه شی | حکم | source |
|---|---|---|
| د ثلاثي مجرد **باب** (د عین حرکت) | **سماعي** — اټکل یې مه کوه | 02-abwab § ۲.۱ |
| د ثلاثي **مصدر** | ډېری **قیاسي**، خو ډېر شاذ هم شته | 06-masdar § ۶.۱ |
| د غير ثلاثي **مصدر** | **ټول قیاسي** | 06-masdar § ۶.۲ |
| کوم **مزید وزنونه** یوې ریښې ته راځي | **سماعي** — تولید یې مه کوه | 02-abwab § ۲.۵ |
| د فعل **تعدي** او د تعدي **حرف** | **سماعي** | 03-sighy § ۳.۷ |
| **الإعلال** ټول قواعد | **قیاسي** — کوډ یې تولیدولی شي | 04-ilal |

```dart
enum Provenance { samai, qiyasi, muwallad }
// muwallad = اپلیکېشن یې جوړ کړی خو په کتابونو کې نه دی موندل شوی
// UI کې دې دا په ښکاره نښه شي
```

### ۲. هر transformation باید خپله قاعده وپیژني

د اپلیکېشن اصلي ارزښت دا دی چې **ولې** ښیي، نه یوازې **څه**.

```dart
class IlalStep {
  final String before;      // "قَوَلَ"
  final String after;       // "قَالَ"
  final RuleId rule;        // RuleId.qalbWawYaAlifan
  final String ruleName;    // "قاعدة قال وباع"
  final String taleel;      // "بدّلت الواو ألفًا لوقوعها متحركة بعد الفتحة"
  final SourceRef source;   // shadha: page1_0145 | irshad: 112
}
```

**په إرشاد الصرف کې هره قاعده نوم لري** — هغه نومونه وکاروه:
`قاعدة عِدَة` · `قاعدة قال وباع` · `قاعدة قُلْنَ طُلْنَ` · `قاعدة خِفْنَ بِعْنَ` ·
`قاعدة لم يَدْعُ` · `قاعدة لتَدْعُنَّ` · `القاعدة الأولى للمتجانسين` …

### ۳. حرکات (تشکیل) اختیاري نه دي

ټول عربي متن باید **بشپړ مشکول** وي. د صرف ټوله معنی په حرکاتو کې ده
(`ضَرَبَ` ≠ `ضُرِبَ`؛ `يَقْتُلُ` ≠ `يُقْتَلُ`).

- ډاټا کې **تل** مشکول وساته
- UI کې د حرکاتو د پټولو اختیار ورکړه (د امتحان لپاره)، خو **ډاټا هېڅکله بې تشکیله مه ساته**
- Unicode normalization کې پام کوه چې حرکات ونه غورځي (NFC وکاروه، `ً`–`ْ` وساته)

### ۴. د اصطلاحاتو ژبه

| مفهوم | اصطلاح چې کاروو | ولې |
|---|---|---|
| صیغې | **حاضر** (نه «مخاطب») | إرشاد الصرف |
| ابواب | **الباب الأول = ضرب يضرب** | إرشاد الصرف / برصغیر |
| د فعل ډولونه | صحیح: سالم، مضاعف، مهموز / معتل: مثال، أجوف، ناقص، لفیف | دواړه کتابونه |

⚠️ **د الفاظو ترجمه:** اصطلاحات په **عربي** پرېږده (باب، صیغه، اعلال، ادغام…)،
تشریح یې په **پښتو** ولیکه. دا هغه څه دي چې طالب العلم ورسره بلد دی.

### ۵. RTL

- ټول UI **RTL** دی (پښتو + عربي)
- `Directionality(textDirection: TextDirection.rtl)`
- د ګردان جدولونه **له ښي څخه کیڼ** ته لوستل کیږي
- عدد او د صیغې شمېره: عربي-هندي ارقام (`۱۲۳`) که کاروونکی وغواړي
