## ۶.۲ مصادر غير الثلاثي — **ټول قیاسي**

| وزن | مصدر | مثال |

| ⤷ **معتل اللام** | **تَفْعِلَة** (یاء حذف، تاء عوض) | زكَّى تَزْكِيَة · ربَّى تَرْبِيَة |
| ⤷ نادر: صحیح یې هم تَفْعِلَة | | جرَّب تَجْرِبَة · ذكَّر تَذْكِرَة · بصَّر تَبْصِرَة · فكَّر تَفْكِرَة · كمَّل تَكْمِلَة · فرَّق تَفْرِقَة · كرَّم تَكْرِمَة |
| ⤷ **مهموز اللام** کله د معتل حکم لري | | برَّأ تَبْرِئَة · جزَّأ تَجْزِئَة *(قیاس: تبريئًا، تجزيئًا)* |
| **أفْعَلَ** | **الإفْعَال** | أكرم إكرامًا · أحسن إحسانًا |
| ⤷ **معتل العین** | نقل + قلب + حذف + **تاء عوض** | أقام **إقامة** · أناب **إنابة** |
| ⤷ (کله تاء حذفیږي، خصوصاً په اضافت کې) | | `وَإِقَامِ الصَّلَاةِ` |
| ⤷ کله **فَعَال** راځي (= اسم مصدر) | | أنبت **نَبَاتًا** · أعطى **عَطَاءً** |

| ⤷ **استفعل معتل العین** | لکه أفعل | استقام **استقامة** · استعاذ **استعاذة** |
| ⤷ ❌ خرج: `الطَّايَر`, `الطَّيْر` — همزه یې قیاسي نه ده | مصدر یې التَّفاعُل، التَّفَعُّل | |

## ۶.۴ اسم الفاعل

> منبع: `page1_0062`–`0064`

**تعریف:** ما اشتُقَّ من المصدر **المبني للفاعل**، لمن وقع منه الفعل أو تعلَّق به.

| اصل | وزن | مثالونه |
|---|---|---|
| **ثلاثي** | **فاعِل** (غالباً) | ناصِر · ضارِب · قابِل · مادّ · راقٍ · طاوٍ · بائع |
| ⤷ که فعل یې **أجوف معلَّ** وي | **الف → همزه** | قال → **قائِل** |
| **غير ثلاثي** | **د مضارع په وزن**: حرف المضارعة → **میم مضمومه**، ما قبل الآخر **مکسور** | مُدَحْرِج · مُنْطَلِق · مُسْتَخْرِج |

**شاذ (بفتح ما قبل الآخر):** `أسْهَبَ فهو مُسْهَب` · `أحْصَنَ فهو مُحْصَن` · `ألْفَجَ فهو مُلْفَج`

**له أفعل چې پر فاعِل راغلي (نه مُفْعِل):**
`أعشب المكان فهو عاشِب` · `أورس فهو وارِس` · `أيفع الغلام فهو يافِع`

### صيغ المبالغة

**پنځه مشهورې:**

| وزن | مثال |
|---|---|
| **فَعَّال** | أَكَّال · شَرَّاب |
| **مِفْعَال** | مِنْحَار |
| **فَعُول** | غَفُور |
| **فَعِيل** | سَمِيع |
| **فَعِل** | حَذِر |

**نورې مسموعې:** فِعِّيل (سِكِّير) · مِفْعِيل (مِعْطِير) · فُعَلَة (هُمَزَة، لُمَزَة) ·
فَاعُول (فَارُوق) · فُعَال / فُعَّال (طُوَال / طُوّال، كُبَار / **كُبَّار**)

### تبادل بین فاعل او مفعول

| حالت | مثال |
|---|---|
| **فاعِل** په معنی **مفعول** (قلیل) | `فِي عِيشَةٍ رَاضِيَةٍ` = مَرْضِيَّة · «الطاعمُ الكاسي» = المطعوم المكسوّ |

| **فَعُول** په معنی **فاعِل** | غَفُور = غافِر |

## ۶.۵ اسم المفعول

> منبع: `page1_0065`

**تعریف:** ما اشتُقَّ من مصدر **المبني للمجهول**، لمن وقع عليه الفعل.

| اصل | وزن | مثالونه |
|---|---|---|
| **ثلاثي** | **مَفْعُول** | مَنْصُور · مَوْعُود · مَقُول · مَبِيع · مَرْمِيّ · مَوْقِيّ · مَطْوِيّ |
| | **اصلونه:** مَقْوُول · مَبْيُوع · مَرْمُوي · مَطْوُوي → وګورئ [`04-ilal-ibdal.md`](04-ilal-ibdal.md) § الإعلال بالنقل |
| ⤷ کله **فَعِيل** | | قَتِيل · جَرِيح |
| **غير ثلاثي** | **د اسم فاعل په وزن**، خو **ما قبل الآخر مفتوح** | مُكْرَم · مُعَظَّم · مُسْتَعان به |

**مشترکې بڼې** (د اسم فاعل او مفعول دواړو ته صالحې، «بحسب التقدير»):
`مُخْتَار` · `مُعْتَدّ` · `مُنْصَبّ` · `مُحَابّ` · `مُتَحَابّ`

**نادر:** مفعول په معنی **مصدر** — «ليس لفلان **مَعْقُول**» = عقل · «ما عنده **مَعْلُوم**» = علم

> ⚠️ **د لازم فعل اسم مفعول** یوازې له ظرف، جار ومجرور یا مصدر سره جوړیږي —
> د **المبني للمجهول** په همغو شرطونو ([`03-sighy-gardan.md`](03-sighy-gardan.md) § المجهول).
